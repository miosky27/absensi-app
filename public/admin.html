Dashboard > Pengaturan
Lokasi Kantor / Cabang & Shift
Absen dianggap valid jika karyawan berada dalam radius SALAH SATU lokasi di bawah. Tips: buka Google Maps di lokasi kantor, tekan lama titik lokasi untuk dapat koordinatnya. Karyawan memilih sendiri salah satu shift saat absen masuk.
Pengaturan gaji (uang makan, uang transport, jatah OFF, dll) sekarang ada di menu Gaji > Pengaturan Gaji.
Password Owner
Password khusus owner, terpisah dari password admin. Dipakai untuk membuka kunci periode gaji.
Backup Data
Unduh semua data absensi, gaji, kasbon, cuti/izin, dan foto dalam satu file .zip. Simpan di tempat aman (misalnya Google Drive) secara rutin.
